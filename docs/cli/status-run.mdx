<Note>
Both commands are registered but not implemented yet. Each prints a placeholder line.
</Note>

## tyr status (planned)

```bash
tyr status
```

Will report what Tyr knows about the project in one place:

- the project profile,
- whether the background process is running,
- the last check results and open findings,
- drift since the last scan, such as a new HEAD or changed file count.

It will also support `--json`.

Until then:

| To see | Use |
| --- | --- |
| Whether the background process runs | `tyr watch` (the header line), or `.tyr/state/daemon.pid` |
| Last check results and open problems | `.tyr/state/engine.json` |
| Current findings | `.tyr/state/findings.json`, or the newest file in `.tyr/reports/` |
| Settings | `tyr config` |

## tyr run (planned)

```bash
tyr run "review my last commit"
tyr run "why is the build failing?"
```

Will send a request in plain language to Tyr's engine or an agent, with the project's context from `.tyr/`, then stream progress and save the result as a report.
