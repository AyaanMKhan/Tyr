```bash
tyr <command> [options]
```

| Command | What it does |
| --- | --- |
| [`tyr init`](/cli/init) | Inspect the repository and create `.tyr/` |
| [`tyr start`](/cli/start-stop) | Start the background process |
| [`tyr stop`](/cli/start-stop) | Stop it |
| [`tyr watch`](/cli/watch) | Follow Claude Code, git, file and check activity live |
| [`tyr config`](/cli/config) | View and change settings |
| [`tyr hooks`](/cli/hooks) | Connect Tyr to Claude Code |
| [`tyr status`](/cli/status) | Show what Tyr knows: profile, process, checks, findings, drift |
| [`tyr run`](/cli/run) | Ask Tyr to do something *(planned)* |

`tyr <command> --help` shows every option with examples.

## Global options

These work with every command:

| Option | Effect |
| --- | --- |
| `-C`, `--cwd <dir>` | Run as if started in `<dir>` |
| `--verbose` | Show extra detail. Implies debug logging |
| `-q`, `--quiet` | Only print warnings and errors |
| `--json` | Print machine-readable JSON to stdout instead of text |
| `--log-level <level>` | Minimum level written to `.tyr/logs/tyr.log`: `debug`, `info`, `warn`, `error`, `silent` |
| `-v`, `--version` | Print the version |
| `-h`, `--help` | Show help |

```bash
tyr --cwd ../api watch
tyr init --json | jq .root
tyr start --log-level debug
```

Each flag has an [environment variable](/configuration/environment-variables) equivalent. An explicit flag always wins.

## JSON output

With `--json`, stdout carries only JSON, never banners or spinners. If a command fails before it can print its own result, it prints one error object instead:

```json
{ "ok": false, "error": { "message": "unknown option '--bogus'", "code": "USAGE", "exitCode": 2 } }
```

## Exit codes

Scripts can branch on the exit code without parsing output:

| Code | Name | Meaning |
| --- | --- | --- |
| `0` | OK | Success, including `--help` and `--version` |
| `1` | FAILURE | The command ran and failed, or an unexpected error |
| `2` | USAGE | Unknown command or option, missing argument, bad value, or a `--cwd` that doesn't exist |
| `3` | NOT_INITIALIZED | No `.tyr/` yet. Run `tyr init` |
| `4` | CONFIG | A `.tyr/` or settings file is invalid, or was written by a newer Tyr |
| `130` | INTERRUPTED | Stopped with `Ctrl-C` |

Errors go to stderr as `error: <message>`, sometimes followed by a `hint:`. For a stack trace, rerun with `--verbose` or `TYR_DEBUG=1`.
